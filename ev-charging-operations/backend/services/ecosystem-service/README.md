# Ecosystem Service

现行第七个后端服务：负责中国国内省级监管与可选省内市级监管目标的协议适配、目标路由、字段映射、可靠上报、回执、漏推/补推、对账和执行证据。

- 自有 schema：`evco_ecosystem`；监管目标、映射版本、监管任务、尝试、回执、对账、连接器配置与密钥引用只在本服务保存。
- 订阅：已登记的主数据、价格、充电订单、告警、监管频率遥测汇总和 V2G 订单事件；具体 Topic/消费组以 [事件目录](../../../contracts/events/README.md) 为准。
- 发布：`evco.ecosystem.regulatory-result.v1`，供运营侧更新只读监管状态和告警投影。
- 禁止：写订单、资产、设备、用户、账务或支付退款事实；直接调用设备 MQTT；向监管目标授予设备控制权。

虚拟电厂及其他第三方的数据共享、控制意图、站点功率计划和设备调控，后续在本服务扩展；在单独变更获批前不得创建相应 Topic、消费者、页面或对外协议入口。
