# Integration Service

外部适配服务：支付、银行、门禁/道闸、开票与通知适配器、回调、重试、原文审计和渠道侧对账。

- 自有 schema：`evco_integration`；外部连接、请求尝试、回调原文、验签、协议映射和渠道原始证据只在本服务保存。
- 订阅：财务支付/退款/付款命令，以及运营通知命令。
- 发布：已验签的支付/退款/付款结果和通知投递结果。
- 禁止：创建账本分录、判断可退款余额、修改售后/订单状态、直接写资产或 MQTT。

国内省市监管不属于本服务：它是当前 W10 **监管内部就绪**范围，由第七个 `ecosystem-service` 承接，真实目标接入另以 C3-R 生产 Go 验收。虚拟电厂及其他第三方平台的数据共享、控制计划和设备调控也不属于本服务，但仅这部分属于 W12 后扩展；同样由 `ecosystem-service` 的后续模块承接，见[监管与外部生态能源协同方案](../../../docs/design/监管与外部生态能源协同方案-v1.md)。

本服务保存的是外部执行证据，不是支付或退款的最终业务事实；最终财务状态只能由 `finance-service` 写入。
