## 解锁规则

1. 任一模块的 API 或 E2E 门禁失败，后继模块不得默认开始。
2. 外部能力缺资料时，仅可按现行计划交付模拟器与关闭态；若要求真实启用，必须由用户在审批日志批准变更。
3. W11 不得把 V2G 建模为负数充电订单；W3–W6 的预留检查不通过时，W11 自动阻塞并报告用户。
4. C1-W、C2-W 和小程序真实通知投递的 Mock 通过不等于真实门禁通过；可以继续不依赖真实渠道的内部模块，但 W12 生产 Go 前真实微信登录、支付、结果通知和原路退款必须通过 E2E。
5. W6 不得把历史旧商户资金迁移为新商户退款事实；W8 不得把个人充值退款计入租户结算，或回写已锁定/已付款账单。两项契约或回归失败时，W8/W12 不得解锁。
6. W12 后外部生态协同未获单独排期、协议和控制安全验收前，不得创建虚拟电厂/第三方相关 Topic、消费者或允许第三方直连设备；W10 监管由 `ecosystem-service` 按现行事件目录达到内部就绪，真实目标接入另以 C3-R 生产 Go。
