# Delivery

交付资料入口，覆盖版本发布、部署说明、客户验收材料和现行执行治理记录。

- `execution/`：当前总控、模块依赖、变更审批、完成证据和一致性核对；是实施过程的唯一事实入口。
- `releases/`：版本发布资料。
- `deployment/`：部署、回滚与运行资料。
- `acceptance/`：客户验收资料。
- [leadership-reports/](leadership-reports/README.md)：面向管理汇报的摘要材料；不替代需求、架构、事件或执行事实。

重复的管理汇报副本和打包件已归档至 [`archive/delivery/`](../archive/delivery/README.md)，本目录只保留唯一现役原件。
