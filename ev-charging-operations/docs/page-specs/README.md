# 页面功能详细清单

> 用途：存放每周模块 Step 2 产出的页面级功能详细清单，作为前后端共同开发的依据。

## 文件命名规则

```
Wx-页面功能详细清单-v1.md
```

- `Wx`：周次（W2、W3、...、W11）
- `v1`：版本号，随审核修订递增

## 产出时机

每周 Step 2（技术设计与契约包）阶段产出，Step 2 审核通过后进入 Step 3 后端开发。

## 页面命名规则

页面标题和路由必须完全对齐 [充电运营平台菜单架构-v4.1](../requirements/充电运营平台菜单架构-v4.1.md) 的一级/二级/三级菜单命名。

```
### X.<页码> <一级菜单 > 二级菜单 > 三级菜单>

| 属性 | 值 |
| --- | --- |
| 菜单归属 | 一级：XXX / 二级：YYY / 三级：ZZZ |
| 路由 | /{一级kebab}/{二级kebab}/{三级kebab} |
```
