## 版本变更摘要

- 将菜单架构调整为“一级业务域、二级子域、三级独立对象、Tab 并列视图”的统一规则。
- 补充平台个人支付/退款渠道、平台向租户结算渠道、结算账户、场站结算方案、付款与回单。
- 补充停车、出入口/车位闸机、园区门禁的业务协同边界；设备接入与 API 密钥保留在 IOT/安全配置范围。
- 明确企业资金由平台统一台账管理，企业拥有使用权，租户不管理企业资金。
- 补充企业协议价：按企业、车辆分组/电卡分组和场站维护专属计费规则，并在订单启动时固化价格快照。
- 补充企业车辆分组、电卡分组、场站定时充电、V2G、监管漏推与补推闭环。
- 补充统一设备接入服务优先的数据边界，以及设备管理中的场站总表、变压器表和正反向分时计量数据。
- 补充场站收益模型、购售电价、占位提醒、收益分析及泰安营销活动全量菜单；“双向充放电”统一更名为“V2G运营”。
- 补充场站数据分析与设备数据分析：支持多场站/多数据点、多个设备/多个功能点的组合查询，每个选中组合展示一条曲线；明确统计口径、采样质量与设备数据存储的优先数据边界。
- 场站定时充电策略以场站、设备和枪口为对象，仅由平台或租户配置，移除 P2、M4 的企业客户配置入口。
- M1、M2“我的”增加独立 V2G 放电入口，覆盖扫码放电、实时数据、放电订单、收益余额/明细与提现记录；收益账户与充电及企业资金隔离。
- M3、M4 调整为商家端移动结构：工作台、场站、数据、订单、我的；车辆和电卡统一归入 M4“我的”，并补充场站/设备实时状况、充电趋势和功率趋势。
- M1、M4 的充电发票从“我的 → 发票服务”进入，订单仅保留订单及售后/对账上下文；M2 不提供发票入口，企业充电发票由企业管理侧与平台对接。
