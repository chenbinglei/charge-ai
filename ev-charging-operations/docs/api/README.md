# API 规范与模块接口说明

- [API 通用接口规范 v1](API通用接口规范-v1.md)：统一响应、分页、错误码、追踪、幂等和版本规则。
- [IAM 用户与角色接口规范 v1](IAM用户与角色接口规范-v1.md)：平台/租户管理用户及角色绑定的资源接口规则。
- [认证与SSO接口规范 v1](认证与SSO接口规范-v1.md)：管理端认证、图形验证码、SSO 免登录与 profile 的资源接口规则。
- [P1 配置接口规范 v1](P1配置接口规范-v1.md)：小程序、支付渠道、结算渠道与基础设置配置的资源接口规则（channel-config-v1.yaml 人读基线）。
- [个人用户主档接口规范 v1](个人用户主档接口规范-v1.md)：M1 个人用户主档与渠道身份映射的管理侧接口规则（personal-identity-v1.yaml 人读基线）。
- [W2 前端 API 对接速查 v1](W2-前端API对接速查-v1.md)：面向前端开发的阶段性对接文档（W2 16 端点：路径、入参/出参示例、错误码与对接要点）。

运行时 OpenAPI、事件与 MQTT 契约的唯一事实仍在仓库根目录 `contracts/`；本目录只放通用接口规则和模块联调说明，不替代已发布契约。
