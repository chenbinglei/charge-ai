# P1 配置接口规范（小程序/支付渠道/结算渠道/基础设置）

> 版本：v1.0
> 状态：W2 模块实施前的强制接口设计基线；本文不是已发布运行时 API。
> 依据：[channel-config-v1.yaml](../../contracts/openapi/channel-config-v1.yaml) v1.0.0、《[API 通用接口规范](API通用接口规范-v1.md)》、《[W2 技术设计与契约包](../design/W2-IAM个人身份与配置技术设计与契约包.md)》。
> 边界：仅覆盖 P1 的渠道/支付/结算配置与平台基础参数管理；真实支付/退款交易归 W6 资金批次与 C2-W/C2-A 独立门禁，不在本接口范围。

## 1. 资源边界

- 四类配置资源：小程序应用档案（`mini_program`）、支付渠道与路由（`payment_channel`）、结算渠道（`settlement_channel`）、平台基础参数/字典/特征开关/审批流/操作日志（`platform_setting`）；全部由 `platform-service` 维护，属平台级数据。
- 渠道凭据（商户密钥、AppSecret 等）只允许受控密钥引用（`credentialRef`）落库；接口与日志永不返回原文，P1 仅显示脱敏引用与校验状态。
- 银联/银盛等条件渠道默认关闭态（`n_a`），不因配置存在即视为已接入；真实渠道验收按 C2-W/C2-A 门禁执行。

### 1.1 鉴权模型（资源 + 读/写两档）

- 本接口涉及的权限码：`mini_program:read`/`mini_program:write`、`payment_channel:read`/`payment_channel:write`、`settlement_channel:read`/`settlement_channel:write`、`platform_setting:read`/`platform_setting:write`。
- 鉴权规则：`GET` 校验 `resource:read`；`POST`/`PUT` 校验 `resource:write`；权限不足返回 `FORBIDDEN`(403)。平台级配置不区分租户数据范围。

## 2. 统一资源接口

| 方法与路径 | 权限码 | 请求模型 | 响应模型 | 中文语义与约束 |
| --- | --- | --- | --- | --- |
| `GET /api/v1/mini-program-apps` | `mini_program:read` | `subjectType`/`environment`/`status`/分页 | `ApiResponse<PageResponse<MiniProgramAppListVO>>` | 按主体、环境、状态分页查询小程序应用档案。 |
| `POST /api/v1/mini-program-apps` | `mini_program:write` | `CreateMiniProgramAppRequest` + `X-Idempotency-Key` | `ApiResponse<MiniProgramAppListVO>` | 新增小程序应用档案；AppID 全局唯一，重复返回 409。 |
| `PUT /api/v1/mini-program-apps/{appId}` | `mini_program:write` | `UpdateMiniProgramAppRequest`（含 `version`） | `ApiResponse<MiniProgramAppListVO>` | 编辑档案、发布版本与灰度/回滚策略；`version` 乐观锁，冲突返回 409 `VERSION_CONFLICT`。 |
| `GET /api/v1/payment-channels` | `payment_channel:read` | `channelType`/`status`/分页 | `ApiResponse<PageResponse<PaymentChannelListVO>>` | 按渠道类型（wechat/alipay/unionpay/yinteng）与状态分页查询。 |
| `POST /api/v1/payment-channels` | `payment_channel:write` | `CreatePaymentChannelRequest` + `X-Idempotency-Key` | `ApiResponse<PaymentChannelListVO>` | 新增支付渠道配置；凭据只传受控引用。 |
| `GET /api/v1/settlement-channels` | `settlement_channel:read` | `status`/分页 | `ApiResponse<PageResponse<SettlementChannelListVO>>` | 按状态分页查询结算渠道。 |
| `POST /api/v1/settlement-channels` | `settlement_channel:write` | `CreateSettlementChannelRequest` + `X-Idempotency-Key` | `ApiResponse<SettlementChannelListVO>` | 新增结算渠道配置（账户、对账周期、扣款方式、限额、风控规则）。 |
| `GET /api/v1/platform-settings` | `platform_setting:read` | `category`/分页 | `ApiResponse<PageResponse<PlatformSettingListVO>>` | 按类别（basic_param/dictionary/feature_switch/approval_flow/operation_log）分页查询。 |

## 3. 关键请求与响应字段

| 模型/字段 | 类型 | 中文说明 | 约束 |
| --- | --- | --- | --- |
| `CreateMiniProgramAppRequest.appId` | string | 小程序 AppID | 必填；全局唯一；重复返回 409。 |
| `CreateMiniProgramAppRequest.credentialRef` | string | 受控密钥引用 | 只存引用不存原文；响应永不回显。 |
| `UpdateMiniProgramAppRequest.version` | integer | 乐观锁版本 | 必填；冲突返回 `VERSION_CONFLICT`。 |
| `CreatePaymentChannelRequest.channelType` | string | 支付渠道类型 | 枚举 `wechat`/`alipay`/`unionpay`/`yinteng`；银联/银盛为条件渠道，默认关闭态。 |
| `CreateSettlementChannelRequest.limitAmount` | integer | 限额 | 整数最小货币单位；禁止浮点。 |
| `CreateSettlementChannelRequest.riskControlRules` | object | 风控规则 JSON | 仅受控扩展字段；不得夹带凭据。 |
| 各 `*ListVO.healthStatus` | string | 渠道执行健康度 | 枚举 `healthy`/`degraded`/`down`。 |
| 关闭态 `status` | string | 渠道/应用状态 | 枚举 `active`/`inactive`/`testing`/`closed`/`n_a`；`n_a` 表示条件渠道不适用。 |

## 4. 后端、前端与测试落地

- 后端目录为域包直挂 `config/{controller,dto,vo,service,service/impl,mapper,entity,cache}`；配置校验、凭据引用登记、关闭态判定在 `service` 编排，Controller 不直连 Mapper。
- 前端目录按业务模块组织，如 `views/config/mini-program/`、`views/config/payment-channel/`、`views/config/settlement-channel/`、`views/config/platform-setting/`；配置页面覆盖加载、空、失败、无权限、版本冲突与关闭态标签；凭据录入仅显示脱敏引用。
- 测试按"AppID 唯一冲突、创建幂等、乐观锁冲突、凭据不回显、条件渠道关闭态、限额整数约束、分页边界"逐项覆盖；每个测试类、方法、夹具和关键 Given/When/Then 代码块写中文说明。
