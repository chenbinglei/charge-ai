## 1. 菜单原则与终端边界

一级菜单表达稳定业务域，二级菜单表达独立工作区，三级菜单表达可直接访问的页面或页签。按钮、弹窗、筛选项、IOT 接口配置、设备协议和调用日志均不作为菜单。

| 编号 | 终端 | 核心边界 |
| --- | --- | --- |
| P1 | 运营管理平台 | 平台/租户经营、企业与运营商业务控制、财务、监管和大屏配置。 |
| P2 | 企业客户管理平台 | 企业管理员的完整业务配置、资金、账务、报表与授权资产运维。 |
| M1 | 个人充电小程序 | 微信手机号授权个人的找站、个人充电、支付、订单和服务。 |
| M2 | 企业用户充电小程序 | 企业账号员工/司机的企业资金或电卡充电与本人企业订单。 |
| M3 | 运营商运营小程序 | 运营商/租户的移动经营、现场运营、告警、工单和订单处置。 |
| M4 | 企业客户管理小程序 | 企业移动查看、待办审批与现场运维；不提供充电启动。 |
| D1 | 运营大屏 | 独立只读展示应用，配置在 P1 发布。 |
