# 充电运营平台功能清单（五端菜单架构优化版）

> 已归档（2026-08-06）：该文保留此前讨论的菜单颗粒度与功能来源，不能作为开发依据。当前资料请使用《[菜单架构 v3](../../../docs/requirements/充电运营平台菜单架构-v3.md)》与《[业务规则基线 v2](../../../docs/requirements/充电运营平台业务规则基线-v2.md)》。

## 1. 菜单架构原则

本清单按“一级菜单 - 二级菜单 - 三级菜单”定义五端产品的信息架构。一级菜单只表达一个稳定业务域；二级菜单是独立工作区；三级菜单是可独立访问的页签、详情页或子页面，不将按钮、筛选项、弹窗重复列为菜单。

### 1.1 产品名称统一

| 编号 | 统一名称 | 原始称呼 | 目标用户 |
|---|---|---|---|
| P1 | 运营管理平台 | 运营商管理后台 / 运营平台 | 平台管理员、运营、财务、运维、客服 |
| P2 | 企业客户管理平台 | 企业充电用户后台 | 企业管理员、车队管理员、企业财务 |
| M1 | 车主充电小程序 | 移动用户端 | 个人车主 |
| M2 | 场站商家运营小程序 | 移动商家端 | 场站负责人、商家、合伙人 |
| M3 | 企业客户小程序 | 企业客户移动端 / 加盟运营商 | 企业管理员、车队管理员、加盟运营商授权人员 |

说明：“加盟运营商”是组织类型和数据权限，不是独立产品；其移动能力复用企业客户小程序。

### 1.2 分类调整说明

| 调整项 | 优化后的原则 |
|---|---|
| 计费模板、电价、占位费 | 统一归入 **价格策略**，因为本质是收费规则和经营策略，不属于资金核算 |
| 交易、对账、发票、账户、分账 | 归入 **资金财务**，因为本质是已经发生的资金、票据和结算处理 |
| 场站权益、会员、白名单 | 会员与白名单只在 **客户运营** 中维护；场站详情仅展示已关联权益并跳转，不重复建设维护入口 |
| 车主、企业客户、车辆 | 统一归入 **客户运营**；场站设备菜单只保留资产和运行能力 |
| 设备实时控制、告警、工单 | 统一归入 **运维管理**；订单菜单只处理订单生命周期 |
| IOT 对接 API | **不作为平台菜单或页面配置**。IOT 的地址、鉴权、Topic、API、Schema、重试及调用日志由部署/集成层管理；运营平台只消费同步的资产、状态、遥测、告警和指令回执数据 |

### 1.3 跨端基础规则

1. 最小运营粒度为充电枪；场站、设备、枪、订单、告警、费率和交易均可追溯。
2. 场站最多绑定一个微信商户和一个支付宝商户；支付、退款必须按订单原商户执行。
3. 小程序与场站是展示关系，不承担支付商户路由；小程序管理不重复维护商户关系。
4. 历史订单固化费率、优惠、白名单、商户与开票主体快照，后续配置变更不重算历史订单。
5. 车主 V2G 收益按“车主 × 场站绑定商户”独立账户管理，不支持跨商户合并余额或提现。
6. IOT 平台负责设备接入、通信协议、遥测采集和原始告警规则；运营管理平台负责业务展示、订单保护、告警处置、工单和经营数据。
