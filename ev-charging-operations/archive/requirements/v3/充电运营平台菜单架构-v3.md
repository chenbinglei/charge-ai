# 充电运营平台菜单架构 v3

> 归档：本文件是历史菜单基线，不再作为当前实现依据。现役资料请使用《[充电运营平台菜单架构 v4.1](../../../docs/requirements/充电运营平台菜单架构-v4.1.md)》与《[充电运营平台业务规则基线 v4.1](../../../docs/requirements/充电运营平台业务规则基线-v4.1.md)》。

## 1. 产品与菜单命名

| 编号 | 统一名称 | 主要使用者 | 规则引用 |
| --- | --- | --- | --- |
| P1 | 运营管理平台 | 平台超级管理员、运营商/租户运营人员、平台运营人员 | R-AUTH |
| P2 | 企业客户管理平台 | 企业管理员、企业车队/财务/运维人员 | R-AUTH |
| M1 | 个人充电小程序 | 微信手机号授权登录的个人用户 | R-START-PERSONAL |
| M2 | 企业用户充电小程序 | 企业管理员创建的员工/司机账号 | R-START-ENTERPRISE |
| M3 | 运营商运营小程序 | 运营商/租户管理员、合伙人、现场负责人 | R-AUTH |
| M4 | 企业客户管理小程序 | 企业管理员、企业车队/财务/运维人员 | R-AUTH |
| D1 | 运营大屏应用 | 指挥中心、展示终端 | R-AUTH |

一级菜单是稳定业务域；二级菜单是独立工作区；三级菜单是独立页面或详情页。按钮、弹窗、筛选条件、IOT 接口参数不作为菜单。

## 6. 菜单边界

| 不建设为平台菜单的内容 | 处理边界 |
| --- | --- |
| IOT API 地址、Token、Topic、设备协议、Schema、通信重试、调用日志 | IOT 平台、部署层或集成层管理。 |
